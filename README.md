# 36104 DVN - Session 2 Streamlit apps

Three Streamlit apps, each deployed separately on Streamlit Community Cloud:

| Folder | Main file | Task |
|---|---|---|
| `uber/` | `uber/uber_pickups.py` | Part C - Streamlit "Create an app" tutorial (Uber pickups) |
| `stars/` | `stars/star_app.py` | Part D - AppStar with a metallicity slider, pair-instability branch and HR diagram |
| `multipage/` | `multipage/Hello.py` | Part E - Streamlit "Create a multipage app" tutorial |

Run locally: `pip install -r requirements.txt`, then run the main file with Streamlit.
